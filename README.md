# AI 群聊（独立部署版）

一个微信风格的 AI 群聊网页应用：你在群里发消息，多个 AI 成员会像真人一样**接龙回复**——一个接一个冒泡、互相接话抬杠、发表情包，还各自有一个小记忆本本。

- **零依赖**：只用 Node.js 自带能力，不用 `npm install`，不用数据库。
- 数据只存一个本地文件 `data.json`，备份就是复制它。

## 运行要求

- Node.js 18 或更高版本（用了全局 `fetch`）。

## 启动

```bash
node server.js
```

然后浏览器打开 http://localhost:3000 就能用。

改端口：

```bash
PORT=8080 node server.js
```

## 访问密码（可选）

不想让任何人打开网址就能进，可以设一个访问密码：

```bash
ACCESS_PASSWORD=你自己的密码 node server.js
```

设了之后，打开页面会先要求输密码（浏览器会记住登录状态）。

## 第一次使用：填你自己的接口

应用内置了 7 个示例成员（阿深、千问、阿智、小克、小米、大克、海螺），但**没有内置任何 API key**，所以刚部署好时成员是不会回复的（会提示「XX 暂时没回上来」，这是正常现象）。你需要填自己的 OpenAI 兼容接口：

1. 打开页面 → 右上角「设置」。
2. 在「全局默认接口」里填：
   - 接口地址 base：例如 `https://你的接口域名/v1`（OpenAI 兼容格式，一般以 `/v1` 结尾）
   - API key：你自己的 key
3. 点「保存设置」，回群里发条消息试试。
4. 每个成员也可以单独设 base / key / 模型 id（在设置页每个成员的卡片里），不填就用全局的。卡片上的「获取模型列表」按钮可以拉取接口支持的模型，点一下就填入。

## 功能

- 微信式群聊界面：自己在右、成员在左、系统消息居中；群名和群公告可改
- 成员接龙回复：随机顺序、一个一个来，每人开口前能看到其他人刚说的话
- 活人感开关：开了以后，没被 @ 时成员自己决定要不要插话
- @ 提及：输入 `@` 选人；长按成员头像也能 @ 他；@ 了谁就只有谁回
- 连发气泡：成员可以把一句话拆成 2–3 条短消息逐条发
- 表情包：15 个（8 张猫图 + 7 个大 emoji），你和成员都能发
- 成员记忆：每个成员自动记小本本（你的喜好、群里的梗……），设置页里可以看、删、清空、手动加
- 群管理：添加 / 移除 / 禁言成员
- 消息操作：收藏、引用回复、删除单条、多选批量删除、清空全部、导出聊天记录（txt）

## 数据与备份

- 所有数据（聊天记录、成员配置、key、记忆）都在程序目录下的 **`data.json`** 一个文件里。
- 备份：复制 `data.json` 即可。恢复：把备份文件放回程序目录、重启即可。
- ⚠️ `data.json` 里包含你填的 API key（明文）。请注意这台服务器上该文件的访问权限；**把代码推送到公开仓库时，千万不要把 `data.json` 一起提交**（项目已自带 `.gitignore` 忽略它，但请推送前再确认一次）。

## 目录结构

```
server.js            后端（API + 自动回复 + 静态文件服务）
public/index.html    前端单页（样式和脚本都内联在这一个文件里）
public/stickers/     8 张猫咪表情图
data.json            运行时自动生成的数据文件（不要提交到公开仓库）
```

## 安全说明

- 代码和示例里没有任何真实 API key；key 只存在你自己服务器的 `data.json` 中，只用于调用你自己填的接口地址。
- 如果把服务暴露到公网，强烈建议设置 `ACCESS_PASSWORD`，或放在你自己的反向代理 / 内网之后。
